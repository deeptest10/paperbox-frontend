# PaperBox - frontend

PaperBox - каталог канцтоварів на HTML, CSS та JavaScript. Дані про товари й користувачів сайт отримує з Django REST API

## Можливості

- Каталог доступний без входу. На першій сторінці відображається до 20 товарів із назвою, описом і ціною
- Користувач може зареєструватися та увійти. Якщо дані реєстрації некоректні, біля відповідного поля з'являється повідомлення про помилку
- Профіль доступний лише після входу. Якщо гість відкриє профіль, сайт перенаправить його на сторінку входу, а після успішного входу поверне до профілю
- Гість бачить посилання «увійти». Після входу замість нього з'являються ім'я користувача з посиланням на профіль і кнопка «вийти». Якщо користувач уже увійшов, сторінка входу перенаправляє його до каталогу або профілю
- Сайт зберігає токени в `sessionStorage`. Коли термін дії access-токена закінчується, сайт отримує новий за допомогою refresh-токена та повторює запит. Під час виходу обидва токени видаляються

## Запуск

Потрібні Python 3 та [бекенд PaperBox](https://github.com/deeptest10/paperbox/tree/auth-api) з гілки `auth-api`. Встановлювати JS-залежності не потрібно.

1. Налаштуйте бекенд за його README. У каталозі бекенду з активованим віртуальним середовищем виконайте:

   ```bash
   python manage.py runserver 8000
   ```

2. В окремому терміналі перейдіть до каталогу `paperbox-frontend` та виконайте:

   ```bash
   python3 -m http.server 5500 --bind 127.0.0.1
   ```

3. Відкрийте http://127.0.0.1:5500/. Обидва сервери мають працювати одночасно.

## Перевірка

Відкрийте `profile.html` без входу. Сайт перенаправить вас на сторінку входу. Увійдіть у свій акаунт або зареєструйтеся та увійдіть. Після цього відкриється профіль з вашим іменем користувача та електронною поштою
