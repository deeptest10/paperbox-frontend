# PaperBox - frontend

Сторінка каталогу канцтоварів на HTML, CSS та JS.

Отримує товари з REST API та показує назву, опис і ціну. Відображає стан завантаження, порожній каталог і повідомлення про помилку. Показує першу сторінку каталогу - до 20 товарів.

## Запуск

Потрібні Python 3 та запущений [backend PaperBox](https://github.com/deeptest10/paperbox) з реалізованим API каталогу у гілці `catalog-api`.

1. Налаштуйте backend за його README та запустіть на порту 8000:

   ```bash
   python manage.py runserver 8000
   ```

2. В окремому терміналі перейдіть в папку frontend та виконайте:

   ```bash
   python3 -m http.server 5500 --bind 127.0.0.1
   ```

3. Відкрийте http://127.0.0.1:5500.

Обидва сервери повинні працювати одночасно. Встановлювати JS-залежності не потрібно.

## Підключення до API

- Frontend: http://127.0.0.1:5500
- Backend: http://127.0.0.1:8000
- Запит товарів: `GET /api/v1/products/`
- Адреса API задана у змінній `API_URL` у файлі `app.js`.

У налаштуваннях backend список `CORS_ALLOWED_ORIGINS` має містити `http://127.0.0.1:5500` та `http://localhost:5500`.

## Перевірка

Перевірено відображення товару з API та повідомлення про помилку після зупинки backend. Після повторного запуску backend й оновлення сторінки товари завантажуються знову.
